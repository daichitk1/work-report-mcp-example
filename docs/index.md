# Work Report MCP

ChatGPTが直前の1依頼で行った作業を、結果・判断・確認状況・残作業として見られるMCP Appです。

このサイトには、現在の仕様、構成、安全性と接続手順を掲載しています。

| 読みたい内容                      | ページ                                          |
| --------------------------------- | ----------------------------------------------- |
| 何を表示し、どんなときに使うか    | [要件定義](./requirements.md)                   |
| Tool、認証、データ、UIの構成      | [設計](./design.md)                             |
| 自分のAuth0とMCP Serverで試す方法 | [セットアップ](./setup.md)                      |
| 実装を読むための入口              | [コードガイド](./code-guide.md)                 |
| データと認証の安全性              | [Security Boundaries](./security/boundaries.md) |

レポートはモデルが整理した内容であり、独立した監査証跡ではありません。ChatGPTとの実接続には、自分のAuth0環境とHTTPSで動くMCP Serverが必要です。
